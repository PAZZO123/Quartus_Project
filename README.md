# MIPS Processor: Quartus Working Files

Working folder for my 32-bit single-cycle MIPS processor coursework: SystemVerilog sources, testbenches, Quartus and ModelSim scripts, and the lab reports. The cleaner version of the design is in the `Single_Cycle_MIPS_Processor` repository.

## Contents

- `*.sv`: full adder, ALU, ALU control, multiplexer and the processor
- `*_tb.sv`: testbenches
- `*.tcl`: scripts to create and compile the Quartus projects
- `MIPS_Project_Report.pdf`: the lab report
